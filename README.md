# AI Content Lab Website

Static portfolio website for AI Content Lab.

## Files
- `index.html` — main website
- `styles.css` — responsive styling
- `script.js` — navigation, reveal animations and contact mailto form
- `assets/` — future images/logos

## GitHub Pages
Upload these files to a public GitHub repository and enable GitHub Pages from the repository's Pages settings.

Replace the placeholder business email in `index.html` and `script.js` with the exact AI Content Lab business email before publishing.
